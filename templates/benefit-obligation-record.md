# Benefit and obligation operating record

Use the [operating procedure](../docs/operations-and-reporting.md), [authorization record](application-approval.md) and [financial-control record](financial-control-record.md). **Blank record: Draft; no actual benefit, obligation, appointment or action is established.** Unknown is not zero. Fill Not applicable only with a reason.

This is a public-safe field design. Complete real private evidence only in the verified custodian's authorized system. A public copy includes permitted metadata and safe opaque references, never private agreements, banking, donor data, credentials or access-bearing evidence links.

| Proposed purpose and existing receiving technical owner | Unknown / Unassigned; no assignment inferred |
| Actual decision, receipt, entitlement, delivery and use dates | Unknown; record each separately and preserve partial/uncertain results |

## Repeatable obligation rows

Create a stable row for each actual obligation. A row may be created at Awarded even when activation is blocked; it cannot create the missing terms acceptance.

| Field | Value or required evidence |
| --- | --- |
| Obligation ID / benefit / prior or amended row | Unknown |
| Actual agreement/version/clause and applicability | Unknown; retain conflict/access limitations |
| Required output, acceptance standard and period | Unknown |
| Recipient/channel and permitted disclosure | Unknown; private details omitted publicly |
| Due kind | Unknown; absolute, relative, recurring or event-only when evidenced |
| Original date/time/timezone or relative rule | Unknown; preserve actual precision and calendar/business-day definition |
| Trigger event and evidence | Unknown; missing trigger prevents a computed due instant |
| Derived due instant / calculation / reviewer | Unknown; no guessed timezone, midnight or trigger |
| Actual owner / reviewer / accepted responsibility | Unassigned / Unknown |
| Current status and next action | Pending or Blocked with reason; an internal checkpoint is distinct from a provider deadline |
| Delivered/report revision and original evidence | Unknown; preserve failed, partial and unexecuted scope |
| Actual independent review | Unknown; exact covered inputs/findings and remaining gaps |
| Actual dispatch attempt / confirmed receipt / provider acceptance | Unknown; separate events, not inferred from report preparation |
| Amendment, deviation or waiver | Unknown; proposed versus actually accepted, exact changed scope and authority |
| Closeout evidence and residual duties | Unknown; required settlement/return/export/retention and item-specific result |

## Renewal, closeout and public handoff

- Current useful need, eligible route and changed terms: Unknown.
- Existing authority still covers renewal, or new exact decision required: Unknown.
- Actual auto-renewal/overage/stop controls and authorized exit plan: Unknown.
- Actual revocation, settlement, verified return or approved title transfer: Unknown.
- Export/deletion/retention requirement and confirmed result: Unknown.
- Final reports, acceptance and surviving obligations: Unknown.
- Item-specific closeout decision, independent reviewer and exact evidence: Unknown / Unassigned.
- Overall closure: Blocked or Partial while required evidence or obligations remain unresolved.
- Public projection review, permitted fields and safe references: Unknown.
- Next authorized action / actual owner / internal follow-up date: Unknown / Unassigned / Unknown.

Use the [award report](award-report.md) for a dated reporting snapshot. It must not overwrite this event/obligation history or turn an unaccepted award into an activated benefit.
