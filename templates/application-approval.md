# Concrete action approval record

Use with the [authorization procedure](../docs/workflow-and-authorization.md). **Default: Draft / no external action approved.** Existing project engineering authorization remains effective for its recorded scope. Reference prior authorization when it already covers the exact action; this blank form neither revokes nor creates it.

This is a public-safe template. A real private packet belongs only in the actual custodian's authorized system. Use one exact action/version per decision; related actions link their distinct decisions.

## Identity and scope

| Field | Value / required record |
| --- | --- |
| Stable approval ID, revision and prior record | Unknown |
| Opportunity ID / issue / provider / program round | Unknown; Not applicable only with reason |
| Action | Select: research, drafting, repository publication, outreach, submission, negotiation, signing, acceptance, activation, spending/reimbursement, account/custody change, public acknowledgment |
| Current record state | Draft; no external action approved by this form |
| Existing authorization and covered scope | Unknown; cite actual standing/prior authority where applicable |
| Project/public-benefit purpose and receiving work | Unknown |
| Legal applicant or contracting party and evidence | Unknown; explain Not applicable for an action making no such representation |
| Selected applicant route and finding | Present community / fiscal-sponsored / independent 501(c)(3): Unknown until assessed |
| Other route findings and limits | Record separately; do not transfer qualification |
| Exact recipient/channel/account and verification | Unknown; public copy contains permitted metadata and safe reference only |
| Reviewed artifact and immutable revision | Unknown; exact form, text, attachments, declarations and agreement/offer versions |
| Proposed scope | Unknown; action, representations, recipients and explicit exclusions |

## Evidence, benefits and restrictions

| Field | Value / required record |
| --- | --- |
| Current eligibility and intake | Applicable program/round/route findings, actual review and unresolved conditions |
| Sources and source-check dates | Official URL/version, claim scope, successful access date, failed attempts/conflicts and limits; review date separate |
| Requested benefit and currency/units | Unknown; separate cash, advertised award, usable entitlement and avoided cost |
| Proposed deliverables and obligations | Unknown; matching funds, reporting, publication, branding and continuing work |
| Maximum permitted commitment and limits | Unknown; amount/currency/term, fees/taxes, recurrence/overage, nonfinancial commitments and verified stop mechanism |
| Eligible funds and financial-control reference | Unknown where needed; accepted #24 revision, actual fund/custodian, reservation, duplicate/payment/reconciliation controls |
| Baseline and actual mandate evidence | Accepted #11 reference plus specific verified facts/mandates needed by this action |
| Legal/financial/independence/privacy review | Actual reviewer/capacity, scope, result, conflicts, recusal, independent replacement and unresolved decisions |
| Restrictions and operating terms | Reporting, branding, publication rights, privacy/data use, portability/export, custody, renewal, overage, termination/return and independence; source clause or reasoned Not applicable |
| Deadline / agreement dates | Unknown until supported; published local date/time/timezone and justified UTC separately |
| Outstanding gates and native issue links | Exact missing evidence and affected action; retain unrelated qualified scopes |

## Actual decision, validity and execution

| Field | Value / required record |
| --- | --- |
| Requester and material interests | Unassigned / Unknown; permitted public attribution only |
| Independent reviewer, capacity and receipt | Unassigned / Unknown |
| Approving person, capacity and authority | Unassigned / Unknown; actual mandate issuer, actions, limits and revocation conditions |
| Distinct signer / host review where required | Unassigned / Unknown; no inference from repository, liaison or budget role |
| Decision | Draft; later Approved, Rejected or Blocked only when actually decided |
| Exact permitted scope and conditions | Unknown; artifact revision, parties, action, recipient/account, limits and unmet conditions |
| Actual approval date and receipt | Unknown; preparation is not approval |
| Validity period or event conditions | Unknown; no invented perpetual authority or arbitrary expiry |
| Re-review triggers and superseded record | Material amendment, applicant/recipient/account/terms/commitment change, new restriction/conflict, expired condition or mandate change; retain old decision |
| Pre-execution comparison and result | Unperformed; compare actual action with still-valid exact approval |
| Executing person and actual capacity | Unassigned / Unknown |
| Actual completion or attempt receipt | Unperformed; action/version/time/outcome and safe reference; reconcile uncertainty before retry |
| Continuing obligations and closeout | Unknown; actual clause, due date/trigger, owner, reviewer and report/renewal/exit receipt |

Approval, execution, provider acceptance, payment and usable activation are different facts. An empty field, proposed condition, PR acceptance or passing validator supplies no missing decision. A change record preserves review/approval and execution history; it cannot retroactively approve a changed action.

## Public projection and private custody

Public candidate: stable ID, permitted purpose/action, state, outstanding gate, cleared category/aggregate and safe decision/delivery references. Record the actual disclosure reviewer, permitted fields and scope before publishing real information.

Private system only: applicant documents, mandates, confidential applications/agreements, donor/payee contacts, bank/payment/tax information, credentials and sensitive access details. Actual custodian, authorized access and retention basis remain Unknown until established. Public references must be safe opaque IDs after review, not access-bearing URLs or hashes of sensitive values.

## Review handoff

- Exact reviewed record/procedure revision and actual reviewer: Unknown / Unassigned.
- Findings, accepted scope, corrections and remaining gaps: Unknown.
- Actual independent review and accepted-delivery reference: Unknown.
- Next evidence/review action and accepted owner: Unknown / Unassigned.
- Selected internal follow-up date, if any: Unknown; separate from a provider deadline.

Unfilled values do not imply approval. The [synthetic unapproved walkthrough](examples/application-approval-unapproved.md) demonstrates the expected behavior without performing an external action.
