The current documentation publishes **20 credits per developer per day**, **15 minutes per credit**, a **30-minute minimum reservation** and a **10-hour/40-credit daily reservation maximum**. Twenty granted credits imply at most five hours of credit-funded time if usable; the larger maximum does not establish an extra twenty-credit grant or rollover. It documents APK installation, process stop, file transfer and Remote Debug Bridge using a local RDB client plus ADB. That published interface does not qualify the current project driver. Device-admin installation is disabled; extra peripherals are unsupported. [S2–S3]

The terms, effective 2026-01-29, require a qualifying registered user and state applications must be “designed solely for use on Samsung devices.” They also require session-content removal, prohibit locking devices, disclaim guaranteed device availability and warn that remote conditions need not match production. The general portal provision covers noncommercial use and treats submitted content as nonconfidential with a broad license; applicable service/account terms must be reconciled for the actual use. These conditions support the conservative Not Pursuing decision above, not an invented waiver. [S4]

Signup is the published service route, not a donation application or award round. The full current authenticated registration, regional agreement and actual user qualification remain uninspected.
