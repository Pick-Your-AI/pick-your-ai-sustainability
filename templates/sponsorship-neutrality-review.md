# Sponsorship neutrality review record — template

Use with the [proposed neutrality policy](../docs/policies/vendor-neutrality-and-sponsorship-ethics-draft.md), [authorization record](application-approval.md) and [financial control record](financial-control-record.md). This is an unfilled review design. **No offer, approval, adoption or execution is created by completing a draft.**

Keep private evidence in the actual authorized custody system. Public copies contain only independently cleared summaries and opaque references. Do not enter credentials, private identities, financial details, confidential terms, sensitive-value hashes or access-bearing links into the repository.

## Identity and scope

| Field | Record |
| --- | --- |
| Stable record ID / linked amendment | Unassigned; reuse the existing arrangement and link previous decisions. |
| Provider/program/round, when applicable | Unknown; internal policies use Not applicable with a reason. |
| Exact proposal/agreement and attachments | Unknown; identify the actual immutable version and all applicable linked terms. |
| Action and public-benefit need | Unknown; identify the particular action and relevant existing N01–N09 need/output. |
| Actual recipient, parties and route | Unknown; assess present community, fiscal host and recognized nonprofit separately before selecting an actual route. |
| Prior authorization | Unknown; reference valid issuer, mandate, action, version, limits and continuing conditions if already supplied. |
| Review date and governing-source dates | Unknown until actual reads; distinguish publication, access, review, decision and execution. |
| Current status | Proposed / under review / revise / decline / unresolved; use an actual decided status only with its evidence. |

## Benefit and valuation

Record each cash, restricted/unrestricted gift, grant, commercial return benefit, credit, service, property donation or loan separately. Keep offered, awarded, received, activated, consumed and realized states distinct.

| Required evidence | Record |
| --- | --- |
| Amount/currency or native units; term; support state | Unknown. Do not replace missing amounts with zero. |
| Actual restrictions and return benefits | Unknown; classify the underlying facts instead of relying on “donation” or “sponsor.” |
| Workload and no-support alternative | Unknown; link the necessary useful scope and an evidenced alternative purchase. |
| Eligible usable amount and actual consumption | Unknown; exclude unused or already-free units from a realized avoided-cost claim. |
| Fees, overage, continuing operation and exit costs | Unknown; preserve each currency, period and uncovered charge. |
| Effort method | Actual packet/clauses, reviewer work, implementation and reporting tasks plus justified time assumptions; Unknown until supplied. |
| Financial-control / receipt treatment | Unknown; link the actual competent issuer/reviewer decision. No donor tax conclusion here. |

## Disclosure and decision

Prepare the exact proposed public language separately from protected evidence. Identify the affected study/recommendation/location, permitted sponsor/support details, material restriction, actual status and reviewer scope. Record who cleared each identity, amount, logo or statement and whether an aggregate could indirectly identify someone.

| Decision field | Record |
| --- | --- |
| Recommended disposition | Proposed acceptable terms / revise / decline / unresolved, with exact reasons. |
| Actual decision | Pending. If later decided, record actual authority, date, version, scope, conditions and reasons. |
| Source/method acceptance | Pending; actual independent review link and exact source revision. |
| Policy adoption, if relevant | Unknown; refer to a separate actual adoption record. |
| Material change / recheck condition | Actual changed term, party, artifact, conflict, mandate, expiry or relevant new evidence; no invented deadline. |
| Authorized execution and real outcome | None recorded. Preserve attempted, failed, uncertain and confirmed separately. |
| Obligations and closeout | Actual reporting/renewal/return events, roles and safe receipt references; Unknown until established. |

An uncertain execution requires reconciliation before a repeat. Do not assume a failed response means no agreement, payment or obligation exists. Do not send a corrective message, cancel or refund unless the actual next action is authorized.

Completing this record does not automatically update an opportunity, mark a research issue Done, adopt a policy, make an agreement or send a communication.
