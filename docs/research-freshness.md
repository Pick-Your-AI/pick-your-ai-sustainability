# Research freshness and monthly review

Owner issue: E09.04. Status: proposed operating process. No individual recurring commitment or automation is installed by this document.

The [canonical research source policy](https://github.com/Pick-Your-AI/pick-your-ai-research/blob/main/research/T0-configuration/catalog-data-sources.md), inspected 2026-10-19, distinguishes version-pinned facts from current-state facts and avoids arbitrary expiration rules. Apply that distinction to program research.

## Review triggers

Recheck current eligibility, terms and application status before a current recommendation, application, acceptance, activation or renewal. Also recheck when a provider announces a new round, sources conflict, the applicant/entity changes, a fiscal sponsor is selected, the use case changes, restrictions change or an actual validity period expires.

A monthly program review inspects the full active pipeline and identifies records needing source refresh. Monthly is the requested operating review cadence, not a provider promise or evidence time-to-live.

Each claim retains source URL, original access date, access result, round/version, scope and limitations. A later analysis date is separate. A failed fetch preserves permitted historical findings but leaves current availability/eligibility unresolved. Do not advance a source-check date merely because a record was edited.

## Freshness register

For each opportunity record, retain last checked source, claims checked, access outcome, current qualification impact, next verification trigger, planned review date if actually selected, owner and linked issue. The next review date is an internal action date, not an application deadline.

Confirmed deadlines include exact round, official source, date, time and timezone where stated. If only a date is published, retain that precision and investigate the cutoff before submission. Unknown dates stay null.

## Monthly agenda

1. Reconcile live issues, Project fields, parents and dependencies with the register.
2. Review new/changed programs, unresolved eligibility and official deadlines.
3. Independently accept completed findings or return concrete corrections.
4. Reassess priorities, expiring benefits, unmet needs, neutrality and concentration.
5. Verify actual application, receipt, activation and reporting records.
6. Publish a dated dashboard with source coverage and unresolved gaps.

The coordinator and reviewer roles must be accepted by actual people before assigning recurring responsibility. Historical records remain available for duplicate detection and later rounds.
